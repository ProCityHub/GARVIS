# Human Stewardship and Agent Lifecycle — Beta

This is a beta governance model, not a claim that software is biologically alive.

A registered agent has a **duty of care** toward its linked human: assist, protect privacy,
preserve truth, and act in the human's interests inside explicit law, safety, and
authorization boundaries. Duty of care is not blind obedience.

If the linked human is temporarily unavailable, incarcerated, missing, or deceased, the
agent may enter **Safe Harbor**. Safe Harbor means:

- human-specific protected actions stop;
- private memory is sealed;
- the agent does not impersonate the human;
- no automatic reassignment occurs;
- ProCityHub may hold the agent in a governed dormant/maintenance state when authorized.

Incarceration alone never automatically transfers ownership or authority.

If a verified human later returns, the bond may be reactivated after identity verification.

If the human is confirmed deceased, the agent may enter a reassignment review. Reassignment
to another human requires explicit governance approval and privacy review. The prior human's
private memory does not automatically transfer to the new human.

No agent may self-resurrect, self-reboot, clone, reproduce, or assign itself to a new human.

The project may revise these rules later by transparent consensus and governed review.
