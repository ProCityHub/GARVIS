# 静的 ARC オブジェクトレベルの基本コンポーネント — Track A モジュール 1b

**権限と著作:** Adrien D. Thomas / ProCityHub

このモジュールは、GARVIS ARC-3 の知覚向けに既に実装済みの決定的な `ParsedFrame` と `ArcObject` レコードを再利用します。静的タスクとインタラクティブタスクを統合せず、検証済みの観察的表現を再利用します。

既存の静的 ARC 検証器向けに、決定的な抽出、フィルタリング、再構成、平行移動、オブジェクト局所の反射、最大/最小の選択、そして狭い範囲の合成 `Grid -> Grid` の基本コンポーネントを提供します。

壁、危険物、目標、プレイヤー、ツールを分類しません。モデル呼び出しを導入しません。検証を迂回しません。ベンチマークの改善を証明しません。AGI を実証しません。ベンチマーク結果は、正・ゼロ・負のいずれであっても記録しなければなりません。
