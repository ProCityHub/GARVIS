# GARVIS オプション B: 許可制のローカルアクセス

GARVIS は、コードに関する質問に対して、範囲を限定した 読み取り専用 のリポジトリ情報を自動で参照できます。
より広範なローカルファイルの参照には、タスクごとの Y/N 承認が必要です。

恒久的な境界:

- バックグラウンド監視はしません;
- カメラ、マイク、位置情報、画面、メッセージへのアクセスはしません;
- ファイル書き込み、コマンド実行、インストール、アップロード、削除はしません;
- シークレット、認証情報、鍵、ウォレット、シードフレーズ、`.env`、`.secrets`、`.git` は読み取りません;
- 承認済みの Termux ルート外にはアクセスしません;
- 権限は期限付きで、単一タスクにのみ適用されます;
- インターネット調査は別系統の承認が必要です;
- 監査対象は GARVIS の操作であり、 Adrien の私的な活動ではありません。
