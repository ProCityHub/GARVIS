# GARVIS オプション B：権限ゲート付きローカルアクセス

GARVIS は、コードに関する質問に対して、範囲が限定された読み取り専用のリポジトリ エビデンスを自動で利用する場合があります。
より広範なローカルファイルの検査には、1 タスクごとの Y/N 承認が必要です。

恒久的な境界:

- バックグラウンド監視はしません;
- カメラ、マイク、位置情報、画面、メッセージにはアクセスしません;
- ファイル書き込み、コマンド実行、インストール、アップロード、削除はしません;
- シークレット、認証情報、鍵、ウォレット、シードフレーズ、`.env`、`.secrets`、`.git` は読み取りません;
- 承認済み Termux ルート外にはアクセスしません;
- 権限は期限付きで、1 つのタスクのみに適用されます;
- インターネット調査は引き続き別の承認経路です;
- GARVIS のアクションは監査対象であり、Adrien の私的な活動ではありません。
