# GARVIS オプション B: 許可で制御されたローカルアクセス

GARVIS は、コードに関する質問に対して、範囲を限定した読み取り専用のリポジトリ情報を自動で利用できます。
より広範なローカルファイルの閲覧には、1 タスク限定の Y/N 承認が必要です。

恒久的な制約:

- バックグラウンド監視は行いません。
- カメラ、マイク、位置情報、画面、メッセージにはアクセスしません。
- ファイル書き込み、コマンド実行、インストール、アップロード、削除は行いません。
- シークレット、認証情報、キー、ウォレット、シードフレーズ、`.env`、`.secrets`、`.git` は読み取りません。
- 承認された Termux のルート外にはアクセスしません。
- 権限は有効期限付きで、1 タスクのみに適用されます。
- インターネット調査は引き続き別個の承認経路です。
- GARVIS の操作は監査対象であり、Adrien の私的な活動ではありません。
