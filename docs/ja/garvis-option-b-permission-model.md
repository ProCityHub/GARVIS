# GARVIS Option B: 許可制のローカルアクセス

GARVIS は、コードに関する質問に対して、限定された読み取り専用のリポジトリ証拠を自動的に使用する場合があります。
より広範なローカルファイルの検査には、1 タスクごとの Y/N 承認が必要です。

恒久的な境界:

- バックグラウンド監視は行いません;
- カメラ、マイク、位置情報、画面、メッセージへのアクセスは行いません;
- ファイルへの書き込み、コマンド実行、インストール、アップロード、削除は行いません;
- シークレット、認証情報、キー、ウォレット、シードフレーズ、`.env`、`.secrets`、`.git` は読み取りません;
- 承認済みの Termux ルートの外部へはアクセスしません;
- 権限は期限付きで、1 タスクのみに適用されます;
- インターネットでのリサーチは別個の承認経路のままです;
- GARVIS のアクションは監査対象であり、Adrien の私的な活動ではありません。
