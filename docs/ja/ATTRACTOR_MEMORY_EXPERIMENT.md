# GARVIS アトラクターメモリ プロトタイプ

著者: Adrien D. Thomas

ステータス: 決定論的ソフトウェア実験

科学的境界: このプロトタイプは、意識、感受性、同一性の持続、真の AGI、生物学的同等性、量子的検証、または物理法則を確立しません。

## 目的

次の機能を持つ Hopfield 方式の連想メモリコンポーネントを構築します:

1. 分散的な相互作用重みに双極パターンを格納します。
2. 完全、部分的、またはノイズを含む手掛かりを受け付けます。
3. 反復的に安定状態へ収束します。
4. 収束、復元精度、エネルギー、および失敗を報告します。

ネットワークの重みがストレージ機構です。ストレージなしにメモリが存在すると記述してはなりません。

## 状態表現

格納されるパターンは -1 と +1 のみを含みます。

想起の手掛かりには、消去または未知の値を表す 0 を含めてもかまいません。

すべてのパターンは同じ長さでなければなりません。

## 重みの構築

次元 n の格納パターン x_k に対して:

W = (1 / n) * sum of outer_product(x_k, x_k)

重み行列は対称でなければなりません。

すべての対角成分は 0 でなければなりません。

想起は、ファイル名、データベースキー、パターン識別子、またはルックアップインデックスではなく、重み行列を使用しなければなりません。

## セトリング規則

決定論的な非同期ニューロン更新を使用します。

各ニューロンについて:

field = sum(W[i][j] * state[j])

field が正の場合、ニューロンを +1 に設定します。
field が負の場合、ニューロンを -1 に設定します。
field が 0 の場合、現在の値を保持します。
field と現在値がともに 0 の場合、+1 を使用します。

1 回のスイープで、すべてのニューロンを 1 度ずつ更新します。

完全な 1 スイープで変更が生じないとき、ネットワークは収束します。

スイープ回数の有限の最大値は必須です。

## エネルギー

完全に双極な状態に対して:

E = -0.5 * state_transpose * W * state

決定論的非同期セトリングの間、エネルギーは増加すべきではありません。

これはソフトウェアの不変条件であり、物理的エネルギーの証拠ではありません。

## 必須測定

各想起結果は以下を報告しなければなりません:

- 最終状態;
- 収束または非収束;
- スイープ回数;
- 状態変更の総数;
- エネルギーの推移;
- 目標が与えられた場合の厳密なターゲット一致;
- 目標が与えられた場合のハミング距離;
- 警告または失敗理由。

## 必須テスト

実装は次をテストしなければなりません:

1. 空パターンの拒否。
2. 次元不一致の拒否。
3. 無効値の拒否。
4. 対称な重みと 0 の対角。
5. 完全な格納手掛かりからの厳密想起。
6. 部分的手掛かりからの想起。
7. 制御されたビット反転ノイズからの想起。
8. 同一シードによる決定論的結果。
9. 有界な非収束の取り扱い。
10. 非同期における非増加エネルギー。
11. 偽アトラクタの報告。
12. 複数パターンにおける容量と干渉。

成功、失敗、あいまいな想起はいずれも可視のままでなければなりません。

## ベースライン

実験は、アトラクタ想起を次と比較しなければなりません:

1. 明示的な最近傍パターンのルックアップベースライン。
2. 学習された連想セトリングを用いずに、消去ビットを決定論的に埋めるノーメモリのベースライン。

別個の実験が事前登録されない限り、比較は記述的です。

## エンジニアリング境界

最初の実装は Python 標準ライブラリのみを使用します。

提案モジュール:

src/garvis/attractor_memory.py

提案テスト:

tests/garvis/test_attractor_memory.py

メモリモジュールが実行してはならないこと:

- ファイルシステムへの書き込み;
- ネットワークアクセス;
- サブプロセス実行;
- Git 操作;
- シークレットへのアクセス;
- モデル呼び出し;
- 外部アクション。

## 将来の GARVIS 統合

後の統合では、アトラクタの出力を任意のコンテキストとして提供する場合があります。

想起された内容には来歴と信頼度を含め、決して無批判の真実として扱ってはなりません。

アトラクタメモリは、セッション履歴、リポジトリエビデンス、科学的主張、承認、および外部アクション権限とは分離されたままです。
