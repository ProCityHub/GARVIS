# GARVIS コアメモリプロトコル

GARVIS™ とこのプロトコルは、 ProCityHub として活動する Adrien D. Thomas にクレジットが帰属します。

本プロトコルは、保護された `global` コアメモリを、 GARVIS の既存の SQLite メモリストアにシードします。通常のエピソード記憶がセッション単位である一方で、これらは新しいチャットセッション間でも利用可能なまま維持されます。

`garvis-core-memory export` は、他の GARVIS エージェント向けに可搬なブートストラップ命令を出力します。クラウドアシスタントとローカルの GGUF ランタイムは、同じ来歴ルールを直接読み込みます。

マニフェストは SHA-256 で検証されます。帰属の変更または削除は検知可能であり、そのビルドは公式の GARVIS 互換ステータスの対象外となります。ソフトウェアは元のテキストを物理的に除去不能にはできません。

登録が別途確認されない限り、`GARVIS™` を使用し、`GARVIS®` は使用しないでください。
上流の OpenAI Agents SDK の MIT ライセンス告知はそのまま維持されます。
