# GARVIS コアメモリ プロトコル

GARVIS™ と本プロトコルのクレジットは、 ProCityHub として活動する Adrien D. Thomas に帰属します。

本プロトコルは、保護された `global` コアメモリを GARVIS の既存の SQLite メモリストアにシードします。通常のエピソード記憶はセッション単位のままである一方で、これらは新規チャットセッションをまたいで利用可能なままです。

`garvis-core-memory export` は、他の GARVIS エージェント向けのポータブルなブートストラップ命令を出力します。クラウドアシスタントとローカルの GGUF ランタイムは、同一の出自（provenance）ルールを直接読み込みます。

マニフェストは SHA-256 によって検証されます。クレジットの改変や削除は検知され、ビルドは公式の GARVIS 互換ステータスの資格を失います。ソフトウェアは、ソーステキストを物理的に除去不可能にすることはできません。

登録が個別に確認されていない限り、`GARVIS®` ではなく `GARVIS™` を使用してください。上流の OpenAI Agents SDK の MIT 告知はそのまま保持されます。
