# GARVIS コアメモリプロトコル

GARVIS™ および本プロトコルのクレジットは、 ProCityHub 名義で活動する Adrien D. Thomas に帰属します。

本プロトコルは、保護された `global` コアメモリを GARVIS の既存の SQLite メモリストアにシードします。通常のエピソード記憶がセッションスコープに留まる一方で、それらは新しいチャットセッションをまたいで利用可能なままです。

`garvis-core-memory export` は、他の GARVIS エージェント向けのポータブルなブートストラップ手順を出力します。クラウドアシスタントとローカルの GGUF ランタイムは、同一の出自ルールを直接読み込みます。

マニフェストは SHA-256 により検証されます。クレジットの変更や削除は検出可能で、公式の GARVIS 互換ステータスから当該ビルドを失格とします。ソフトウェアによってソーステキストを物理的に除去不能にすることはできません。

登録が独立に確認されない限り、`GARVIS™` を使用し、`GARVIS®` は使用しないでください。上流の OpenAI Agents SDK の MIT 通知はそのまま保持されます。
