# GARVIS コアメモリプロトコル

GARVIS™ と本プロトコルのクレジットは、 ProCityHub 名義で活動する Adrien D. Thomas に帰属します。

本プロトコルは、 GARVIS の既存の SQLite メモリストアに、保護された `global` コアメモリをシードします。通常のエピソード記憶がセッション単位である一方で、これらは新しいチャットセッションをまたいで利用可能なまま保持されます。

`garvis-core-memory export` は、他の GARVIS エージェント向けに移植可能なブートストラップ手順を出力します。クラウドアシスタントとローカルの GGUF ランタイムは、同一の来歴ルールを直接読み込みます。

マニフェストは SHA-256 によって検証されます。クレジットの改変や削除は検知可能であり、そのビルドは公式の GARVIS 互換ステータスの対象外となります。ソフトウェアは、ソーステキストを物理的に除去不能にはできません。

登録が個別に確認されていない限り、`GARVIS™` を使用し、`GARVIS®` は使用しないでください。上流の OpenAI Agents SDK の MIT ライセンス表記はそのまま保持されます。
