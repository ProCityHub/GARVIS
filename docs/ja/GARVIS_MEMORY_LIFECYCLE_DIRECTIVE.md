# GARVIS メモリ ライフサイクル ディレクティブ v1

**権限:** Adrien D. Thomas / ProCityHub  
**リポジトリ:** `~/GARVIS`  
**ブランチ:** `feature/memory-lifecycle-v1`

このディレクティブは、証拠を考慮するローカル メモリ ライフサイクルを導入し、その後 Git ワークフローを自動で実行します: 検証、コミット、プッシュ、プルリクエスト、CI 監視、スクワッシュ マージ、ブランチ削除、ローカル `main` 更新。

## メモリ設計

- 作業記憶、エピソード記憶、意味記憶、手続き記憶、コア メモリ、残痕トレース メモリ。
- 保持は時間とともに減衰し、反復/想起で強化されます。
- 証拠ステータスは顕著性や感情と切り離して保持します。
- 関連想起はローカル GGUF モデルに到達する前に制限されます。
- 弱い古い言語は小さな“ゴースト トレース”に圧縮される場合があります。
- トレース記録はプロンプト想起から除外され、事実としては数えられません。
- コア/保護メモリは自動でトレースされることはありません。
- 自動メンテナンスは決してハード削除しません。
- 明示的な忘却には `FORGET-<memory_id>` が必要です。

これは心理学に基づく機能的なソフトウェアのたとえです。生物学的なシミュレーションではなく、意識を確立するものでもありません。

## ビルド境界

このディレクティブは、検証または GitHub の失敗があれば停止します。モデルの重み、資格情報、`.secrets`、秘密鍵、ローカル データベースをコミットしません。メッセージ送信、取引、送金、コンテンツ公開は行いません。
