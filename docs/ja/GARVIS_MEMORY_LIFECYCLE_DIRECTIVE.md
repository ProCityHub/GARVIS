# GARVIS メモリ ライフサイクル 指令 v1

**権限:** Adrien D. Thomas / ProCityHub  
**リポジトリ:** `~/GARVIS`  
**ブランチ:** `feature/memory-lifecycle-v1`

この指令は、ローカルで証拠認識型のメモリ ライフサイクルを導入し、その後 Git ワークフロー（検証、コミット、プッシュ、プルリクエスト、CI 監視、スクワッシュ マージ、ブランチ削除、ローカル `main` の更新）を自動で実行します。

## メモリ設計

- ワーキング、エピソード、セマンティック、手続き、コア、残留痕跡メモリ。
- 保持は時間とともに減衰し、反復や想起によって強化されます。
- 証拠ステータスは、顕著性や感情とは分離されます。
- ローカル GGUF モデルに到達する前に、関連リコールは制限されます。
- 弱く古い言語情報は小さな「ゴーストトレース」に圧縮される場合があります。
- 痕跡記録はプロンプト リコールから除外され、事実として数えることはできません。
- コア／保護済みメモリは自動で痕跡化されることは決してありません。
- 自動メンテナンスは決して完全削除を行いません。
- 明示的な忘却には `FORGET-<memory_id>` が必要です。

これは心理学に着想を得た機能的なソフトウェアのアナロジーです。生物学的シミュレーションではなく、意識を確立するものでもありません。

## ビルド境界

この指令は、いかなる検証または GitHub での失敗でも停止します。モデル重み、認証情報、`.secrets`、秘密鍵、ローカル データベースをコミットすることは決してありません。メッセージ送信、取引、送金、コンテンツ公開を行うことも決してありません。
