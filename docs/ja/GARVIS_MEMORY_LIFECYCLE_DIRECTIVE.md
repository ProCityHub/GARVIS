# GARVIS メモリライフサイクル指令 v1

**責任者:** Adrien D. Thomas / ProCityHub  
**リポジトリ:** `~/GARVIS`  
**ブランチ:** `feature/memory-lifecycle-v1`

このディレクティブは、ローカルでエビデンス認識型のメモリライフサイクルを導入し、その後に Git ワークフローを自動実行します：検証、コミット、プッシュ、プルリクエスト、CI ウォッチ、squash マージ、ブランチ削除、ローカルの `main` 更新。

## メモリ設計

- 作業記憶、エピソード記憶、意味記憶、手続き記憶、コア記憶、残留痕跡記憶。
- 保持は時間とともに減衰し、反復／想起によって強化されます。
- エビデンスの状態は、顕著性や感情とは分離して保持されます。
- 関連する想起は、ローカルの GGUF モデルに到達する前に制限されます。
- 弱く古い言語情報は小さな「ゴースト痕跡」に圧縮される場合があります。
- 痕跡記録はプロンプトでの想起から除外され、事実として数えることはできません。
- コア／保護されたメモリは自動的にトレースされることは決してありません。
- 自動メンテナンスは決してハードデリートを行いません。
- 明示的な忘却には `FORGET-<memory_id>` が必要です。

これは心理学に着想を得た機能的なソフトウェアのアナロジーです。生物学的シミュレーションではなく、意識を確立するものでもありません。

## ビルドの境界

このディレクティブは、いかなる検証または GitHub の失敗でも停止します。モデルの重み、クレデンシャル、`.secrets`、秘密鍵、ローカルデータベースをコミットすることは決してありません。メッセージ送信、取引、送金、コンテンツ公開を行うことも決してありません。
